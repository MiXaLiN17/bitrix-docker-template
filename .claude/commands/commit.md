Создай коммит для staged изменений в основном репозитории (`src/`).

Шаги:
1. Запусти `git -C src diff --staged` чтобы увидеть что изменилось
2. Получи имя текущей ветки: `git -C src branch --show-current`
3. Извлеки ID задачи — это числовое значение после первого `-` в имени ветки.
   Например: ветка `KUPP-6340` → ID задачи `6340`.
   Если ветка не содержит `-` или после `-` нет числа — спроси пользователя: «Не удалось определить ID задачи из ветки. Укажи ID задачи вручную (или введи "нет" чтобы пропустить):»
4. Определи тип: feat, fix, refactor, docs, chore, test
5. Напиши сообщение в формате:
   - Subject: `type(#ID): описание на русском языке` — максимум 72 символа
   - Body (опционально): что и зачем (не как) — на русском языке
6. Запусти `git -C src commit -m "сообщение"`
7. Покажи результат

Правила:
- Все git команды выполняй с флагом `-C src`
- Никогда не используй "update files" или "fix stuff"
- Если изменения затрагивают разные области, предложи разбить на отдельные коммиты
- Не добавляй файлы автоматически. Коммить только то что уже в staged
